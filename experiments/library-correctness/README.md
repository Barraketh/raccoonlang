# Kernel-independent proof experiment

This experiment attempts the proof comparison requested after the TinyGEMM,
A3b and pair-GEMM client ports. Those ports established useful interface and
lowering results, but did not prove that every kernel generated by the library
satisfies `gpu/OBLIGATIONS.md`.

**The complete library theorem is still unproved.** This experiment provides
checked universal semantic proofs for retirement and communicating endpoints,
plus separation, participation, resource, output and claim proofs. The new [primitive copy-ring library](RING_DESIGN.md) adds actual CUDA lowering and arbitrary-client barrier, native-template and parity proofs, assembled in `RingLibraryProofs.everyProgram`. It is one stage in one CTA, with a discarded scalar read and no compute/output API. Its [friction log](RING_DESIGN_FRICTION.md) links the detailed Luna proof logs. The retirement
fragment has a lowering certificate for its actual CUDA blocks. Concrete failed
proof attempts against the existing interfaces and the remaining obligations are
recorded explicitly.
No result depends on the correctness of a particular GEMM or attention kernel.

## The theorem actually checked

The model tracks a peer resource's live endpoint and pending asynchronous stores.
Its interpreter faults on issuing or finishing an unavailable endpoint, or closing
an endpoint that remains live or has pending work. A complete store wait retires
both the stores and the endpoint. Runtime branch choices, loop counts and the
leader predicate are inputs to execution, independent of eager generation.

`Retirement.sound` proves:

```text
forall code, mode, before, after,
  Typed(mode, code, before, after) ->
  forall leader, runtime, initial,
    at(before, initial) ->
    Post(at(after), run(code, leader, runtime, initial))
```

`Post(Q, fault)` is `False`. Thus this is a semantic preservation proof by
induction over arbitrary code, using the generic Hoare composition proofs in
`../compositional-machines/Contracts.rac`. It is not an accessor returning a
stored protocol certificate. It covers arbitrary nesting of sequences, branches,
loops, leader arms and resource scopes. In particular, the proof does not infer
runtime coverage from a callback's one execution during eager generation.

`Frame.preserves` proves that every admitted leader-only arm preserves **any**
predicate on the peer resource. `Frame.peerUnchanged` instantiates that predicate
with equality to the entire initial state. This holds on either rank, for every
runtime input, even when the resource is initially live or has pending stores.
The model's leader-local action abstracts work on a separate resource; it cannot
issue, retire or allocate the peer resource.

`Dependent.Program` is an ordinary sealed indexed command description.
`Dependent.everyProgram` proves that **every** value of this type runs without
fault and ends with no live endpoint and no pending stores, on either rank, for
all branch choices and loop counts. It carries a derivation whose *semantic
soundness* is separately proved by `Retirement.sound`.

`Elaboration.infer` returns evidence about the exact input code, or rejects it.
`Elaboration.program` packages a root program with equality to that input code.
The accepted-source theorem is generic in code and evidence. State annotations
and proof arguments need not appear in client syntax: the tested inference
procedure reconstructs them from the command tree. This is ordinary Raccoon code;
no compiler feature, quoting mechanism or evaluation-strategy change was added.
It does not yet elaborate arbitrary Raccoon callbacks or the full cursor API.

## What connects the proof to CUDA

`Target.compile` recursively emits `Cuda.Block` and proves `Target.Interprets`
for that exact block. The relation's atom and control rules define a **contract
semantics** for this fragment. They associate concrete CUDA templates with
abstract transitions, summarizing A34/A35 and warp reconvergence. `Target.Correct`
requires both this interpretation and its universal semantic safety proof.
`Target.everyProgram` proves that result for an unknown `Dependent.Program`.

The drain implementation uses the shared `Core.bulkWait`/`Core.onLaneZero` lowering
expression used by `Core.finishStores`. Its specification independently requires
lane-zero `bulkWait(complete, 0)` followed by warp synchronization. Source programs
cannot pair a valid transition with an arbitrary emitter. Loop lowering threads a
fresh-name counter; the concrete inspection kernel also passes the existing
structural check and checker-soundness theorem.

**This is not a refinement proof from full CUDA/PTX execution to the model.**
`Interprets` is the proposed specification of this restricted target interface;
its primitive rules are not derived from a general interleaving semantics. Scope
opening/closing includes ghost ownership supplied by an enclosing shell; the same
CUDA scoped block can also have a transparent interpretation. Memory allocation,
separation, initialized contents, mapping to actual CTA ranks, arbitrary conditions
and cross-thread synchronization are not inferred from a bare block. The fragment
uses a single abstract store region and fixed output coordinates. Its example
intentionally repeats those coordinates, so it does **not** satisfy S5. It is
an inspection artifact, not a replacement GPU library or a kernel to benchmark.

## Comparing the three language routes

| Route | What was actually attempted | Result |
|---|---|---|
| Current Core plus reflection | A generic structural theorem; a contract naming a linear context; a conditional semantic bridge from reflected-client interpretation | Structural theorem checks. Direct linear-value contract is rejected. Semantic bridge checks only given the missing logical interpretation. Typing reflection is not implemented. |
| Existing full cursor API | A contract naming its actual emitter via `GpuMachine.unpack` | Also rejected by `LinearInType`. Bundling tokens with the context did not make emitter history available in propositions. Its previous client ports acquire no universal semantic proof from this experiment. |
| A primitive machine typing judgment | Represented its proposed derivations by `Retirement.Typed`, proved soundness, and elaborated any derivation into `Dependent.Cmd` | The modeled judgment uses the same semantic theorem and CUDA lowering proof. No native compiler judgment was implemented. |
| Ordinary dependent typing plus elaboration | Indexed commands, evidence-producing phase inference, generic preservation/frame proofs, certified CUDA lowering | All check using the current language. This is the only route whose evidence production and universal fragment proof are both implemented here. |

`Bridges.rac` deliberately makes all three candidates discharge the same target
contract. The reflection bridge requires `CoreInterpretation(p)`: an admissible
plan and equality of its certified lowering to `p`'s actual AST. That is the
**result** needed from a logical-relations proof over well-typed clients, not a
replacement name for `HasType`, and not something syntax reflection supplies.
The fixture trying to pass an arbitrary `Core.Program` instead is rejected.
The bridge is deliberately restricted to this fragment; failure to provide it
does not prove that a complete reflection-based proof is impossible.

A separate probe adds a constructor call inside a **temporary copy** of Core's
defining module. It creates a `Program` that puts `__syncthreads()` under
`threadIdx.x == 0` in a 32-thread CTA. The real structural checker, its soundness
proof and `Core.render` accept it. The probe verifies the actual body and which
threads satisfy its guard. It is emitted but never launched. This is **not** an
exploit available to a client of unchanged Core: the added constructor has module
authority. It shows why the semantic theorem cannot follow just from the existing
representation fields. To reason from sealing about all *produced* programs,
we need a client-typing/production theorem or an invariant carried by the type.

## Continuation: remaining obligations

The [remaining-obligation ledger](OBLIGATION_LEDGER.md) describes the additional
proofs and precisely what is still missing for S1–S6 and M1–M24. It supersedes the
original retirement-only coverage inventory.

The earlier communicating-endpoint theorem is `Scheduler.everyKernel`: arbitrary typed producer
and consumer commands, independent runtime loop counts and arbitrary scheduler
choices yield only permitted, safe raw transitions. Waits block without consuming
a command; asynchronous completion is a separate event. `Coupled.noRace` connects
this execution to an explicit synchronization graph, proves distinct actors'
accesses have fresh identities, and derives happens-before paths. Both are
kernel-independent source-command theorems for this restricted contract model.
The CUDA/PTX refinement of its synchronization events remains unproved.

Other checked generic theorems cover shared interval separation and bounds,
expression uniformity and collective participation traces, tensor allocation and
access bounds, output and publication permissions, row/schedule injectivity,
atomic claim exclusivity and the actual native register-budget predicate. They
have different proof boundaries; the ledger distinguishes execution-relation
results from source-command and actual-target results.

## What the experiment supports

For the implemented slices, ordinary dependent typing is sufficient: type
formation supplies a derivation, ordinary induction proves its execution
contract, and lowering is checked against independent exact templates. The new
primitive-ring theorem is `RingLibraryProofs.everyProgram`, covering an unknown
actual library program and arbitrary runtimes/schedules. It also constrains the
enclosing kernel and launcher. The proof is substantial; the friction logs record
repetitive state cases, explicit equality transport and compiler issues.

No native state-machine judgment or typing reflection implementation was tried
in this continuation. They would still need soundness relative to the same
primitive contracts. Their possible benefit to proof ergonomics remains an open
comparison; ordinary typing supporting the theorem does not decide it.

My recommendation is to develop a proof-carrying command IR using ordinary
indices and keep a convenient imperative surface through elaboration. Retain eager
evaluation. Treat the current full cursor facade as a client-interface result,
not the proof architecture. The single-stage mbarrier copy ring now refines those communicating endpoints
with primitive initialization, bytes, phase observation, drain and invalidation
audits, native parity and exact CUDA assembly. The next extensions are multiple
stages, usable compute values, tensor completion and output authority. The pair,
alpha and register-restoration protocols remain unfinished. Those semantic arguments should precede a commitment to a new
compiler judgment or whole-language reflection. Keep the common target semantics
independent of which language route produces its evidence.

The complete goal remains: a theorem over arbitrary well-typed library clients
that implies **all S1–S6** under the documented assumptions. This experiment has
not established that theorem for Core, the full cursor API or a complete
replacement. It has narrowed the architectural question and supplied checked
proofs and explicit obstructions rather than kernel-specific evidence.

## Reproducing the result

```sh
python3 experiments/library-correctness/run.py
sbt validate
```

The runner discovers all accepted modules and deliberately rejected fixtures,
requiring each rejection's expected diagnostic at `Rejected.bad`. It renders the
retirement fragment and primitive-ring client and checks host C++ syntax, runs
the temporary Core representation probe, and rejects 33 semantic/backend
mutations (16 earlier mutations and 17 primitive-ring mutations). See the ledger for the
new proofs and their boundaries. The current run passes 71/71 checks (42 accepted,
29 rejected), all 33 mutations are rejected, and `sbt validate` passes formatting
and all 936 tests. None of the emitted artifacts is executed on a GPU, and PTX is not compiled by these host syntax checks.
Production compiler/library implementation was not changed by this experiment;
the earlier ports' changes remain in the workspace.
